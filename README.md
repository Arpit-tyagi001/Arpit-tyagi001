## 🤖 HireWise AI

**AI-powered Resume Analysis & Career Intelligence Platform**

HireWise AI combines traditional NLP/ML techniques with LLMs to analyze resumes, evaluate ATS compatibility, identify JD skill gaps, and generate safer resume improvements.

### Key Features

* 📄 Resume PDF/DOCX parsing
* 📊 10-dimension ATS scoring engine
* 🎯 JD skill-gap matching
* 🧠 TF-IDF + cosine similarity
* ✍️ AI-powered resume rewriting
* 🛡️ LLM hallucination guardrails
* 🔐 JWT authentication
* 👤 User-level data isolation
* 📥 Tailored DOCX export
* 🧪 Automated security & regression tests

**Stack:** `React` `TypeScript` `FastAPI` `Python` `SQLAlchemy` `scikit-learn` `Groq`

</td>
